# Release Notes

## v1.0.0 — first public build

The first public build of **Free Dictionary** — a fast, fully offline
English-to-English dictionary for Android, built with Flutter.

### Highlights

- 📴 **100% offline** — the entire dictionary is bundled in the app. No
  account, no tracking, no internet needed, ever.
- 🔍 **Instant search** with live suggestions across 108,000+ entries.
- 🗣️ **Idioms** — 14,800+ idiom records, every one with a usage example.
- 🔤 **Pronunciation (IPA)** — text transcriptions with US/UK accent labels
  for 36,000+ words, including inflected forms (*read* — /ɹid/,
  UK /ɹiːd/, past /ɹɛd/).
- 🪞 **Homographs** — same spelling, different meaning & pronunciation
  (*read, bass, tear, wind, lead, dove*…), each reading mapped to its
  meaning.
- 🧩 **Usage patterns** — prepositions, phrasal verbs & collocations
  (43,500+ records) with side-by-side comparison, plus verb forms.
- 🔗 **Verified word relations** — synonyms, antonyms, homophones and
  related terms that all resolve inside the dataset.
- 🕘 **Search history** with recency, most-searched, faved, saved and A–Z
  filters.
- 📚 **Favorites & named collections** with multi-select management,
  move-between-collections flows, and on-the-fly collection creation.
- 🌗 **Light & dark themes** (system default respected).
- ✍️ Long-press any definition or example to select and copy.

### Install

1. Download `free_dict.apk` (next to this file).
2. Open it on your Android device and allow installing from that source if
   asked.
3. That's it — the app never needs a network connection.
